
# Flight of Mind

Flight of Mind is a serious game made in Unity that transforms established cognitive assessments into engaging airport-themed minigames. The project was created by Yulee Oh, Hannah Huang, Connor Wang, Daniel Li, and Nico Ortiz Neidhart under the mentorship of Professor Sang Nam and Professor James Casey at the Virginia Serious Games Institute, George Mason University.

## Getting Started/Installation
Game ZIP file can be downloaded here: https://drive.google.com/file/d/12AZ5vTcPlXIKkKfkqjAPqYP2XMOAhSUH/view?usp=sharing

After extracting the ZIP:
- **macOS (Recommended):** Launch the `Flight-of-Mind-MAC` application.
- **Windows:** Run `Flight of Mind.exe`
- **Web:** https://yuleedev.itch.io/flight-of-mind

## Controls

- **Mouse:** Navigate menus and interact with all minigames.

- **Spacebar:** Used only during the Radar Watch minigame.

## How to Play
(Each game comes with an instructions screen and quick practice to get a feel for the controls as well!)

### Landing Routes

- Click the plane to pick it up and start drawing.

- Draw a route through each checkpoint in order (1 → 2 → 3).

- In Part B, alternate between numbers and letters (1 → A → 2 → B → 3 → C...).

- Reaching a checkpoint out of order counts as an error.

### Cargo Logistics

- Using your mouse, drag the top crate between columns to match the target arrangement.

- Try to solve each puzzle in as few moves as possible.

### Radar Watch

- Press **Space** once during each clear radar sweep.

- Do **not** press Space when the warning symbol is displayed.

- Extra or incorrect presses count as errors.

Enjoy your flight!
